# 🧩 Proyecto: Componente QR Code

Este proyecto consiste en el desarrollo de un **componente de Código QR** utilizando **Astro** y **Tailwind CSS**.  
El objetivo es aplicar los conocimientos sobre **componentes**, **maquetación**, **estilos responsivos** y **utilidades CSS** para construir un diseño limpio, moderno y adaptable a diferentes dispositivos.

### ✨ Reflexión final

Comparte brevemente tu experiencia durante el desarrollo del proyecto.  
Puedes responder a preguntas como:

- ¿Qué fue lo más fácil o lo más difícil de realizar?  
Lo más fácil para mí fue la parte de la estructura del HTML, ya que solo se trataba de organizar los elementos como la imagen, el título y el texto dentro de una tarjeta. Lo más difícil fue lograr que el diseño se viera igual al de la referencia, especialmente ajustar el tamaño de los elementos, los espacios y el interlineado utilizando las clases de Tailwind, ya que todavía estoy aprendiendo qué hace cada atributo y cómo afectan el diseño.

- ¿Qué parte disfrutaste más del desarrollo?  
La parte que más disfruté fue investigar y ver tutoriales para poder entender mejor cómo funcionan las clases de Tailwind y cómo se aplican para modificar el diseño. Esto me ayudó a comprender mejor cómo pequeños cambios pueden afectar mucho la apariencia final de la página.

- ¿Qué conceptos nuevos aprendiste?  
Entre los conceptos nuevos que aprendí están el uso de componentes en Astro, cómo centrar elementos utilizando Flexbox con Tailwind, cómo controlar el ancho de los elementos y cómo ajustar el interlineado y los espacios entre textos.

- ¿Cómo aplicarías lo aprendido en proyectos futuros?
En proyectos futuros creo que podré aplicar lo aprendido para organizar mejor mis páginas y trabajar de manera más eficiente con estilos, especialmente utilizando Tailwind para ajustar el diseño sin necesidad de escribir CSS desde cero.
